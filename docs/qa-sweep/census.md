## Note

Batch runs share gvar/inventory state across quests, so a `completed` in the matrix is a
*candidate* — always re-run the emitted `quest-drive-cmd:` recipe fresh (from --create)
before committing a golden. New Reno (newr2 11/11 stuck) and San Francisco are the
richest untapped veins for the deferred driver capabilities.
